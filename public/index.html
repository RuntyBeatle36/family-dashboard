        Debug Tools

        Performance Overlay

        Shows FPS, CPU, memory, disk, and temperature (plus GPU info on a Pi, where available).

        Graphics Benchmark

        Runs every Frosted Glass × Animated Sky combination on this screen (heavy rain and overcast clouds for each weather tier), measures frame rate and CPU, and recommends the highest settings that stay smooth. Takes about 3 minutes; touch is locked while it runs. Your settings are restored when it finishes. The latest results are saved on the server at /api/benchmark.

        Device Login

        The username and password for signing in to this Pi itself (console or SSH). Each unit gets its own random password on its first boot. Only shown here, on this screen.

        Test Audio

        Plays/speaks immediately, ignoring the alert sound and read-aloud settings. Use this to check the Pi's audio output itself, separate from alert settings.

        Preview Sky Time

        See the sky, sun and moon at another time of day. Needs Animated Sky (Settings ▸ Graphics) set to Reduced or Full. Live returns to the real time.

        Simulate Weather

        Force a visual to preview animations. Resets on next weather refresh.

        Simulate Alerts

        Show a fake alert banner to preview each severity level. Clears on next alert refresh.
